# Aprende a programar en la era de la IA

Recursos, consejos y enlaces para quien está empezando (o retomando) a programar ahora que la IA forma parte del día a día del desarrollo. Pensado para la comunidad: cualquiera puede sugerir cambios abriendo un issue o un pull request.

📝 **Blog:** [techinnovatehub en Medium](https://medium.com/@techinnovatehub) — artículos sobre IA, programación y tecnología.

## Consejos para empezar

- **Aprende los fundamentos antes que el framework de moda.** La IA te ayuda a escribir código, pero si no entiendes lo que genera no vas a poder depurarlo ni mejorarlo. Lógica, estructuras de datos y cómo funciona el lenguaje que elijas van primero.
- **Usa la IA para entender, no solo para copiar.** Pídele que te explique el código línea a línea, que te proponga alternativas, o que te haga preguntas tipo examen sobre lo que acabas de escribir.
- **Escribe proyectos pequeños y termínalos.** Un proyecto terminado de 200 líneas enseña más que diez a medias de 2000.
- **Lee código de otros.** Repositorios open source populares en GitHub son la mejor fuente para ver cómo se organiza un proyecto real.
- **Aprende a hacer buenas preguntas.** Tanto a la IA como en foros: describe qué esperabas, qué pasó de verdad, y qué has intentado ya.
- **No dependas de un único asistente de IA.** Compara respuestas entre herramientas distintas cuando algo no te cuadre; te ayuda a detectar errores y sesgos.
- **Cuida lo que pegas en un chat de IA.** Nunca compartas claves, contraseñas ni datos de clientes reales en un prompt.

## Enlaces útiles

**Fundamentos y cursos gratuitos**
- [freeCodeCamp](https://www.freecodecamp.org/) — cursos completos y gratuitos, con certificado.
- [The Odin Project](https://www.theodinproject.com/) — ruta completa de desarrollo web full-stack.
- [CS50 de Harvard](https://cs50.harvard.edu/x/) — introducción a la ciencia de la computación, gratis.
- [roadmap.sh](https://roadmap.sh/) — rutas de aprendizaje visuales por especialidad (frontend, backend, IA, DevOps...).

**Documentación de referencia**
- [MDN Web Docs](https://developer.mozilla.org/es/) — la referencia de HTML, CSS y JavaScript.
- [Python.org — Documentación oficial](https://docs.python.org/es/3/)

**IA aplicada a programar**
- [Anthropic Docs](https://docs.claude.com/) — documentación de Claude y la API.

**Practicar**
- [Exercism](https://exercism.org/) — ejercicios con mentoría gratuita en decenas de lenguajes.

- [GitHub Skills](https://skills.github.com/) — cursos interactivos oficiales de GitHub (Git, Actions, Pages...).

**Comunidad**
